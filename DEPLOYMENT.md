# Deploy to Vercel

## Drag and drop

1. Go to Vercel
2. Add New Project
3. Drag this folder into Vercel
4. Deploy
5. Open the generated URL on your phone

## GitHub

1. Create a repo named `split-history-guide`
2. Upload all files
3. Import repo into Vercel
4. Framework: Other
5. Build command: blank
6. Output directory: blank
7. Deploy

## Google My Maps import

1. Open `index.html`
2. Download `split-history-stops-google-my-maps.csv`
3. Open Google My Maps
4. Create a new map
5. Import the CSV
6. Choose `Address` as the location field
7. Choose `Name` as the title field
8. Save the map
