# Overview

Purpose: make every stop in the Split History Companion easy to navigate.

This update adds:
- all 30 latest stops
- exact Google Maps pin links
- walking directions for each stop
- route chunks that avoid Google waypoint limits
- CSV import for Google My Maps so all pins can appear together

Design choice:
A single Google Maps URL with 30 pins is unreliable. Google My Maps import is the most reliable Google-native approach for a true all-pins map.
